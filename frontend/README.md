# @rag-wiki/frontend

React 19 + Vite SPA for RAG Wiki: upload documents, ask questions, read
citation-backed streamed answers.

This package is part of a pnpm workspace. Run commands from the repository root:

```bash
pnpm dev        # this app on :5173, API on :5000
pnpm test       # both suites
pnpm verify     # the full CI gate
```

See the [root README](../README.md) for setup, and
[docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md) for how streaming and citation
rendering work.
